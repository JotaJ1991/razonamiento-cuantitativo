## Cómo navegar

| Acción | Control |
|---|---|
| Avanzar | `→` · `Barra espaciadora` · `Av Pág` · botón **Siguiente** |
| Retroceder | `←` · `Re Pág` · botón **Anterior** |
| Ir al inicio / final | `Inicio` / `Fin` |
| Pantalla completa | `F` |
| Saltar a una diapositiva | Clic en los puntos de la barra inferior |
| En móvil o tablet | Deslizar con el dedo |

La diapositiva 13 contiene dos preguntas de opción múltiple con retroalimentación inmediata:
basta con hacer clic en una respuesta.

## Detalles técnicos

- Un solo archivo `index.html`, sin dependencias ni frameworks.
- Las fotografías de la docente van incrustadas en base64, así que el archivo funciona
  también sin conexión y puede enviarse por correo o WhatsApp tal cual.
- Las fotografías de contexto se cargan desde Unsplash; si no hay conexión, cada una
  degrada a un degradado con ícono en lugar de mostrar un recuadro roto.
- `.nojekyll` evita que GitHub Pages procese el sitio con Jekyll.
